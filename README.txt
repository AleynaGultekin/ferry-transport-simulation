Ferry Transport Simulation - Run Instructions

1. Open a terminal in this SourceCode folder.
2. Compile: javac *.java
3. Run: java FerrySimulation

Note: visualization.enabled is set to false in simulation.properties so the program can run safely in terminal/online grading environments without GUI display errors.
The Java Swing visualization can be enabled by changing visualization.enabled=true on a local computer with a graphical desktop.


If the visualization interface causes any environment-related issue,
set visualization.enabled=false in simulation.properties and rerun the program.
